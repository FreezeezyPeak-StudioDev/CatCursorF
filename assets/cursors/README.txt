------------------------
CAT CURSOR by DUCK_BERET
------------------------

This cursor is based on the cat enemy from my game
Hyper Bun Buster: Rocket Hammer Action! It's also
the "cassmaPolite" emote on my Twitch stream at
https://twitch.tv/CassMakesGames



NOTE: The "Link select", "Busy" and "Working in background" cursors have
      two options! You can pick the A or B option, whichever you prefer.

------------
INSTALLATION
------------

WINDOWS 11:

- Unzip the contents of the zip file to a folder
- Go to Settings -> Accessibility -> Mouse pointer and touch
- Click "Customize pointer image"
- Click one of the "Browse" buttons (e.g. the one under Normal Select),
  navigate to your folder and choose the appropriate .cur/.ani file (e.g.
  "Cat - Normal Select.cur")
- Repeat for all of the pointer images

WINDOWS 10:

- Unzip the contents of the zip file to a folder
- Open Control Panel, choose Mouse, click the Pointers tab
- In the Customize section, click on one of the pointers (e.g. Normal Select)
- Click "Browse...", navigate to your folder and choose the appropriate
  .cur/.ani file (e.g. "Cat - Normal Select.cur")
- Repeat for all of the pointer images
- In the Scheme section, click Save As..
- Type a name for your pointer scheme then click OK
